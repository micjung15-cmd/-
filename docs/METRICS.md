# 지표 정의서

대시보드와 노트북에 나오는 숫자의 계산식과 제외 조건입니다.
**정의가 여기 없는 숫자는 화면에 올리지 않습니다.**

> "제외 조건"이나 "근거"가 비어 있으면 아직 검토를 안 한 것입니다.

### 배송 지연일 `delay_days`

| | |
|---|---|
| 계산식 | `실제 수령일 − 약속 예정일` (일 단위) |
| 부호 | 음수 = 약속보다 빨리 도착 / 양수 = 지연 |
| 제외 조건 | 수령일이 없으면 `NULL`. **0으로 채우지 않습니다** — 0으로 채우면 '정시 도착'으로 집계되어 지연율이 실제보다 낮아집니다 |
| 정의 위치 | `sql/base.sql` |

### 지연율

| | |
|---|---|
| 계산식 | `지연일 > 0 인 주문 ÷ 지연일을 알 수 있는 주문 × 100` |
| 제외 조건 | 수령일 결측 주문은 분자·분모 양쪽에서 제외 |
| 주의 | 분모가 '전체 주문'이 아닙니다. 전체 주문으로 나눈 값과 다릅니다 |

### 평균 리뷰 점수

| | |
|---|---|
| 계산식 | 리뷰가 달린 주문의 `review_score` 산술평균 |
| 제외 조건 | 리뷰 없는 주문 제외 (점수를 알 수 없으므로) |
| 주의 | 리뷰를 남기는 고객은 양극단에 몰리는 경향이 있습니다. 전체 고객이 아니라 **리뷰를 남긴 고객**의 만족도입니다 |

### 1점 리뷰 비율

| | |
|---|---|
| 계산식 | `해당 구간에서 1점을 준 주문 ÷ 그 구간 전체 주문 × 100` |
| 왜 따로 보나 | 평균이 완만해도 최저점 비율은 급격히 튀는 구간이 있습니다. 평균만으로는 놓칩니다 |
